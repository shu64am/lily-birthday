# Lily Birthday — A Surprise From Chirag

A romantic, mobile-friendly birthday and proposal webpage made for Lilly by Chirag.

## Included experience

- Midnight countdown with animated birthday cake and candles
- Photo slider with arrows, dots and mobile swipe support
- Typing love letter from Chirag
- Six interactive reasons why Chirag loves Lilly
- Forever-story timeline
- Secret message reveal
- Proposal section with Yes celebration and playful No button
- Confetti, floating hearts and celebration chimes
- Original soft romantic instrumental love tune

## Run locally

Keep `index.html` and `lilly-love-tune.wav` in the same folder, then open `index.html` in a browser. Click **Play love song** to start the music because modern browsers require a user interaction before audio playback.

## Personalize photos

The slider currently uses romantic placeholder images. Replace the four Unsplash image URLs inside `index.html` with Lilly’s real photos and update the captions if desired.

## GitHub Pages

This is a static HTML project and can be hosted with GitHub Pages. In the repository settings, open **Pages**, choose the `main` branch and the root folder, then save.
